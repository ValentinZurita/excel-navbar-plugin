Support

Need help with Sheet Navigator? The public GitHub repository is the support channel for questions, bug reports, and feedback.

Please open a GitHub issue with your Excel platform, browser or desktop version, a brief description of what happened, and any non-sensitive reproduction steps.

Contact support

Use GitHub issues for support. Do not include private workbook contents, credentials, or other sensitive information in an issue.

Open a GitHub issue View repository

Before reporting a problem

  1. Confirm that Excel is signed in with the account where the add-in was installed.
  2. Restart Excel if the add-in does not appear after sideloading.
  3. If you are using Excel on the web, refresh the workbook tab and reopen the add-in.
  4. If the issue involves a workbook action, try to reproduce it in a test workbook that contains no sensitive data.
